## 📖 Sobre o Jogo

Desenvolvido utilizando a **Godot Engine 4**, Futebol de Rua é um jogo de plataforma 2D inspirado no universo do futebol.

Enfrente desafios dinâmicos, evite faltas, encare a arbitragem e garanta a vitória antes do apito final!

## 🎮 Controles

| Ação | Tecla / Comando |
| :--- | :--- |
| Mover | A e D ou ⬅️ e ➡️ |
| Pular | W ou ⬆️ |
| Chutar | C |
| Pausar | Enter |

## 🏆 Destaques

- Mecânicas ágeis de plataforma 2D com temática de futebol.
- Animações exclusivas de arbitragem, cartões e personagens.
- Trilha sonora e efeitos sonoros imersivos de estádio.
- Cenários e desafios inspirados no futebol de rua.

## 🛠️ Tecnologias utilizadas

- **Engine:** Godot Engine 4
- **Linguagem:** GDScript
- **Gênero:** Plataforma 2D
